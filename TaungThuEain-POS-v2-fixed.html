Admin / Staff စီမံခန့်ခွဲမှု

ဝန်ထမ်းခွင့်ပြုချက်ကို Firestore users/{uid} စာရွက်စာတမ်းထဲတွင် Admin က စီမံရမည်။ UI ခလုတ်ဖျောက်ခြင်းတစ်ခုတည်းသည် လုံခြုံရေးမဟုတ်ပါ။

ဝန်ထမ်းအတွက် အချက်အလက်မြင်ခွင့်

ရွေးထားသော ဝန်ထမ်းတစ်ဦးချင်းစီအတွက် ခွင့်ပြုချက်ကို သီးခြားသိမ်းနိုင်သည်။

စတင်အသုံးပြုရန်

Firebase Console → Authentication → Users တွင် အီးမေးလ်အကောင့် ဖန်တီးပါ။ ထို့နောက် Firestore users collection တွင် Document ID ကို ထိုအကောင့်၏ UID နှင့်တူအောင် ဖန်တီးပြီး role: "admin" သို့မဟုတ် "staff" ထည့်ပါ။
